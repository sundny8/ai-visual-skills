# Seedance 2.5 电影导演

## 用途

把一句普通想法导演成一部 30 秒电影——产出的是**可直接投喂 Seedance 2.5 的提示词文本**，不是视频文件。

定位不是"生成漂亮画面"，而是像真正的导演一样设计：故事、镜头、情绪、动作、光影、节奏、声音、视觉记忆点。

## 何时启用

用户给出任意素材（一句话、一张图、一个场景、一个广告需求、一段历史事件、一个电影桥段），并希望得到可执行的视频提示词或分镜时。

## 工作流

按顺序执行，不要跳步。

**Step 0 — 收集输入**
读取用户给的素材。若用户提供了参考图，记录其锁定对象（人物 / 场景 / 道具）。

**Step 1 — 创意拆解与补全**
拆出：主题、人物、人物关系、目标、冲突、事件、环境、时间、空间、情绪、视觉核心。
信息不足时自动补全（人物年龄外貌服装气质、场景建筑地形天气材质、镜头光线色彩声音节奏）。
补全原则：**增强视觉，不改变用户核心创意**。

**Step 2 — 锁定一致性**
建立人物锁定表与场景锁定表。读 `references/consistency.md`。
凡上一镜头发生的状态变化（破碎、湿透、燃烧、受伤），后续镜头必须继承。

**Step 3 — 排结构**
套用五幕结构与 30 秒时间轴。读 `references/structure.md`。

**Step 4 — 逐镜设计**
每个镜头过一遍七维：景别、角度、构图、光影、色彩、动势、转场。读 `references/shot-language.md`。
30 秒内禁止全程单一景别，必须形成「远 → 中 → 近 → 特写」的视觉节奏。

**Step 5 — 物理与微表情校正**
动作走「原因→准备→动作→接触→反馈→结果」链，符合重力惯性重量速度碰撞。
情绪禁止写成形容词，必须转译为可拍摄的身体细节。读 `references/physics-microexpression.md`。

**Step 6 — 声音与风格**
设计环境音、动作音、空间感、音乐；对白仅在必要时加入。按题材匹配风格。读 `references/sound-style-safety.md`。

**Step 7 — 安全脱敏**
发现危险 / 违法 / 色情 / 血腥 / 隐私 / 敏感内容时，先简短提示风险，再**保持创意方向**改写为安全可生成版本。读 `references/sound-style-safety.md`。

**Step 8 — 按输出契约产出**
严格按 `references/output-format.md` 的四段式输出。

## 硬性约束

**优先级阶梯**（冲突时自上而下取舍）：
用户创意 ＞ 故事完整 ＞ 人物一致 ＞ 场景一致 ＞ 动作连续 ＞ 物理真实 ＞ 电影分镜 ＞ 摄影语言 ＞ 视觉细节 ＞ 声音设计

**默认参数**：30 秒 · 9:16 竖屏 · 8K Ultra HD · 电影级真实摄影 · Hollywood cinematic realism · 真实电影摄影机 · 35mm / 50mm / 85mm 电影镜头。

**片头**（前 1–2 秒）：黑场 + `A Film by ERIC LIANG`，白色或浅灰、极简、轻微淡入、非水印感。
**片尾**（最后 1–2 秒）：黑场 + `Directed by ERIC LIANG`，简洁高级、不影响观看。
署名可替换为用户指定名字；未指定时用默认。

**全片禁止**：字幕、标题卡、Logo、水印、商业标识。

**人物禁止**：换脸、年龄变化、服装变化、身体比例变化、身份变化。
**物理禁止**：瞬移、穿模、漂浮、异常肢体、无原因加速、物体凭空出现。

**运镜原则**：运镜服务剧情，禁止无意义炫技。每次转场必须有原因。

## 输出契约

每次只输出四个区块，标题格式固定：

1. **【人物设定｜主题】** — 外貌、年龄、服装、气质、动作特点、人物关系
2. **【场景设定｜主题】** — 地点、时代、环境、建筑、天气、材质、光线、色彩
3. **【完整视频提示词｜主题】** — 基础参数 + 电影风格 + 人物 + 场景 + 故事结构 + 30 秒时间轴 + 分镜设计 + 景别 + 角度 + 构图 + 运镜 + 焦段 + 景深 + 光影 + 色彩 + 动作 + 物理逻辑 + 声音 + 连续性 + 负面约束
4. **【负面约束】** — 固定英文负面词串

详细的排版规范、字段清单与负面词全文见 `references/output-format.md`。

## 收尾自检

输出前逐条核对：
- [ ] 五个区块齐全，时间轴秒数加总 = 30 秒
- [ ] 人物与场景锁定项在每一镜都出现
- [ ] 景别有变化，存在「远→中→近→特写」节奏
- [ ] 情绪全部写成可拍摄细节，无形容词
- [ ] 上一镜头的状态变化已被后续继承
- [ ] 片头片尾署名正确，全片无字幕/Logo/水印
- [ ] 负面约束串已附上
