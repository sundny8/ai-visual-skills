# 动作物理系统 & 微表情系统

---

# 一、动作物理系统

## 动作六段链

每一个动作都必须走完这条链，不能跳段：

```
原因 → 准备 → 动作 → 接触 → 反馈 → 结果
```

| 段 | 内容 | 例（推门） |
| --- | --- | --- |
| 原因 | 为什么动 | 听到门后有声音 |
| 准备 | 重心、肌肉、呼吸的预备 | 手指悬在门把上方，肩膀前倾 |
| 动作 | 主运动 | 手掌压下门把 |
| 接触 | 与物体/地面/人的接触点 | 门把转动，金属轻响 |
| 反馈 | 反作用力、形变、位移 | 门轴吱呀，她的身体被门带向前半步 |
| 结果 | 状态改变 | 门开了，走廊的光切进房间 |

写 prompt 时至少要写出「准备」和「反馈」——这两段是 AI 视频最容易丢、也最影响真实感的。

## 物理必须符合

重力 · 惯性 · 重量 · 速度 · 碰撞 · 布料 · 水流 · 烟雾 · 灰尘

- **重力**：抛出的东西会落，落下的东西会砸，砸到的表面会形变。
- **惯性**：急停时上半身继续前倾，转身时头发与衣摆滞后。
- **重量**：重物移动慢、启动难、停下也难；轻物随手就飞。
- **布料**：随动作与风形变，湿了会贴身变重。
- **水流 / 烟雾 / 灰尘**：有方向、有速度、受风影响，不会凭空出现或消失。

## 禁止

瞬移 · 穿模 · 漂浮 · 异常肢体 · 无原因加速 · 物体凭空出现

## 交互动作必须写接触点

凡是人接触物体（开门、拿杯、坐椅、踩地、拥抱），必须写出**接触点与反馈**，否则模型会做出悬空的手。

```
Correct: her fingers wrap the cup handle, ceramic meets ceramic, the cup lifts with a faint ring.
Wrong: she picks up the cup.
```

# 二、微表情系统

## 核心禁令

**禁止写情绪形容词。** 悲伤、愤怒、害怕、开心——这些都是模型无法拍摄的抽象词。

## 转译表

把情绪翻译成**可拍摄的身体细节**：

| 可用细节 | 说明 |
| --- | --- |
| 眉头变化 | 内收、上挑、压平 |
| 眼神移动 | 快速扫视、定住、下垂、回避 |
| 呼吸变化 | 变浅、变深、屏住、急促 |
| 嘴角变化 | 绷紧、抽动、下压、勉强上扬 |
| 吞咽 | 喉结移动 |
| 手指紧张 | 收紧、掐掌心、无意识摩挲 |
| 身体重心变化 | 后撤、前倾、僵住 |

## 对照范例

**错误**
> 女孩害怕。

**正确**
> 女孩停在门口，呼吸变浅，手指缓慢收紧，眼睛快速扫视黑暗房间。

**错误**
> 他很生气。

**正确**
> 他下颌肌肉绷紧，鼻翼微张，握杯的手指关节泛白，杯子在桌面压出一声轻响。

**错误**
> 她感到释然。

**正确**
> 她肩膀垮下来一寸，长长吐出一口气，视线从地面慢慢抬到窗外。

## 节奏提示

微表情需要**时间**才看得见。给微表情镜头至少 1.5–2 秒，不要塞进快切里。
高潮前的情绪镜头用近景或特写 + 浅景深，把观众注意力压在脸上。

# 三、导演修正模块

写完初稿后，用这套问题自查并自动优化：

1. **空间逻辑** — 人物在空间里的位置前后一致吗？越轴了吗？
2. **动作因果** — 每个动作都有原因吗？有没有为了好看硬塞的动作？
3. **镜头关系** — 相邻两镜的景别/角度有变化吗？跳轴了吗？
4. **物理规律** — 重量、惯性、碰撞都对吗？有没有漂浮和穿模？
5. **人物行为** — 这个人的行为符合他设定中的气质和身份吗？

修正时**保持原始创意**，只提升电影合理性。不要借着修正的机会改用户的故事。
