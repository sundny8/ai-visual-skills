# 一致性锁定系统

连续 30 秒内，人物和场景必须像同一次拍摄。一致性塌了，片子就废了。

---

## 一、人物一致性锁定

建立**人物锁定表**，每个主要人物一张，全片逐字复用，不得改写措辞。

| 锁定项 | 说明 |
| --- | --- |
| 脸型 | 例如 oval face, defined jawline |
| 五官 | 眼型、鼻型、唇型 |
| 年龄 | 具体数字，不要写"中年" |
| 肤色 | 含色调，例如 warm bronze undertone |
| 发型 | 形态 + 束法 |
| 发色 | 含光泽描述 |
| 体型 | 身高感、肩宽、体态 |
| 服装 | 材质 + 颜色 + 剪裁，逐件列出 |
| 饰品 | 位置 + 材质，例如 thin silver chain with a small heart pendant |
| 气质 | 例如 composed, guarded, restless |

### 禁止

换脸 · 年龄变化 · 服装变化 · 身体比例变化 · 身份变化

### 写法要点

把锁定表写成一段**紧凑的英文人物描述块**，在每一镜的 prompt 里原样复制，而不是每镜重新措辞。措辞一变，模型就换人。

---

## 二、参考图规则

用户提供参考图时，先判定它锁定什么：

| 参考图类型 | 锁定 |
| --- | --- |
| 人物参考 | 锁定人物（脸、发、装） |
| 场景参考 | 锁定环境（建筑、地形、光位） |
| 道具参考 | 锁定物品（形状、材质、颜色） |

**禁止错误复制**：不要把人物参考图里的背景当成场景设定，也不要把场景参考图里的人当成角色。

---

## 三、场景一致性系统

场景必须保持稳定：

建筑结构 · 道路 · 地形 · 家具 · 天气 · 光线 · 时间 · 材质 · 空间关系

建立**场景锁定表**，写法与人物锁定表相同：写一段紧凑英文场景块，逐镜原样复制。

---

## 四、状态继承规则（最容易翻车的地方）

**上一镜头发生的任何状态变化，下一镜头必须继承。**

| 事件 | 后续必须保持 |
| --- | --- |
| 玻璃破碎 | 保持破碎，碎片位置不变 |
| 衣服湿了 | 保持湿，颜色变深、贴身 |
| 火灾 | 保持燃烧状态 |
| 受伤 | 血迹、破损服装持续存在 |
| 打翻的液体 | 地面保持潮湿与残渍 |
| 散开的头发 | 保持散开 |
| 沾上泥土 | 保持脏污 |
| 打开的门窗 | 保持打开状态 |

### 写法

在每一镜的描述末尾加一句连续性锚点，例如：

```
Continuity: the shattered glass on the floor remains from the previous shot; her left sleeve is still soaked and darkened.
```

不要指望模型自己记住。每一镜都要显式声明继承关系。

---

## 五、光线与时间连续性

- 全片光线方向保持一致（除非剧情中有光源变化，且变化要有可见原因）。
- 时间不跳变：如果是黄昏开场，全片维持黄昏光，不要中途变成正午。
- 天气不跳变：下雨就下到底，除非有转晴的过渡镜头。

---

## 六、自检

输出前对每一镜问三个问题：

1. 这一镜的人物描述块，和上一镜**逐字一致**吗？
2. 这一镜的场景描述块，和上一镜**逐字一致**吗？
3. 上一镜留下的物理状态，这一镜有声明继承吗？

三个都答"是"才通过。
