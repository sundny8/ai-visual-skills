# 声音导演 · 风格匹配 · 安全脱敏

---

# 一、声音导演系统

声音是 30 秒短片里最被低估的一层。它决定"像不像电影"。

## 四个层次

### 1. 环境音 Ambient
风 · 雨 · 城市底噪 · 森林 · 机械嗡鸣

选择依据：场景。选一层主环境音 + 一层极轻的次级环境音，不要堆叠。

### 2. 动作音 Foley
脚步 · 衣服摩擦 · 碰撞 · 呼吸

原则：**只有画面里发生的动作才配声音**。手没碰杯子就不要有杯子的声音。
关键动作音可以放大到不真实的比例——这是电影感的来源。

### 3. 空间感 Space
回声 · 混响

- 空旷大厅 → 长混响
- 小房间 → 短混响、干燥
- 户外 → 几乎无混响
- 地下空间 → 低频轰鸣 + 金属反射

### 4. 音乐 Music
按情绪设计，不按题材设计。

| 情绪 | 音乐方向 |
| --- | --- |
| 悬疑 | 低频持续音 + 稀疏高频点 |
| 紧张升级 | 节奏加速 + 层叠 |
| 悲情 | 单件弦乐 + 长音 |
| 希望 | 由暗转明的和声推进 |
| 动作 | 打击乐驱动 |

**节奏原则**：音乐在 12–20 秒（冲突升级段）开始进入，20–27 秒（高潮）达到最强，27–30 秒骤停或留白。骤停比渐弱更有力。

## 对白规则

**只有必要时才加入对白。**

需要时：
- 符合人物身份与年龄的用词
- 自然口型，与发音同步
- 表情与语气一致
- 真实停顿——人说话有停顿、有气口，不要写成连珠炮

不需要时：用画面和声音讲完故事。30 秒通常容不下两句以上的对白。

# 二、风格自动匹配

识别用户素材属于哪一类，套用对应风格：

| 类型 | 风格方向 |
| --- | --- |
| 电影 | 专业电影摄影，自然光，克制运镜 |
| 纪录片 | 真实观察，手持，可用跳切，无配乐或极简配乐 |
| 广告 | 高级商业视觉，产品高光，精致布光，节奏干脆 |
| MV | 节奏视觉化，剪辑点贴音乐，色彩大胆 |
| 动画 | 完整世界规则，物理可风格化但必须自洽 |
| 游戏 | 真实游戏电影感，英雄视角，动感运镜 |
| 恐怖 | 空间压迫 + 声音设计，留白多于画面 |
| 喜剧 | 铺垫 → 误导 → 反转 |

匹配风格时**不要改变用户的核心创意**，只改变表达方式。

# 三、创意增强模块

在不改变用户核心主题的前提下，自动增加：

- **视觉钩子** — 开场 5 秒内的记忆点
- **环境互动** — 让人物与场景产生物理接触（推开的东西、踩过的水洼、拂过的枝叶）
- **动作细节** — 给主动作加一个小的附带动作
- **情绪变化** — 至少一次情绪转折
- **小冲突** — 一个阻碍或意外
- **高潮设计** — 唯一的视觉最高点
- **结尾记忆点** — 最后 3 秒的一个画面

**禁止改变用户核心主题。** 增强是加血肉，不是换骨。

# 四、安全脱敏模块

## 触发条件

危险 · 违法 · 色情 · 血腥 · 隐私 · 敏感内容

## 处理流程

1. **简短提示风险** — 一两句话说明哪部分有风险，不要长篇说教。
2. **保持创意方向** — 不改变用户的叙事意图和情绪目标。
3. **改写为安全可生成版本** — 用暗示替代直给。

## 改写手法

| 原内容 | 安全改写 |
| --- | --- |
| 直接的血腥伤害 | 只拍反应与后果（倒下的影子、远处的声音、地面上的物件） |
| 明确的暴力行为 | 用光影、遮挡、剪辑暗示，不拍接触瞬间 |
| 露骨内容 | 拍氛围、局部、隐喻，用留白代替呈现 |
| 真实可识别的私人场所 | 泛化为同类场景，去掉可识别特征 |
| 真实人物的负面情节 | 改为虚构角色 |

**核心**：观众不需要看到，只需要"感觉到发生了"。暗示永远比直给更高级，也更安全。
