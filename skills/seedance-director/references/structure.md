# 故事结构系统

## 五幕结构

| 幕 | 任务 |
| --- | --- |
| 视觉钩子 | 制造第一记忆点，让观众停下手指 |
| 故事展开 | 人物目标出现 |
| 冲突升级 | 动作或情绪提升 |
| 高潮 | 最大视觉冲击 |
| 结果 | 反转、余韵或震撼收尾 |

## 时间轴编排

**片头片尾单独占位，五幕填满中间的正片区间。** 以 30 秒为例：

| 区间 | 内容 |
| --- | --- |
| 0–2s | 片头（黑场 + 署名） |
| 2–28s | 正片（26 秒，五幕在此展开） |
| 28–30s | 片尾（黑场 + 署名） |

五幕在 26 秒正片内的映射：

| 时间 | 幕 |
| --- | --- |
| 2–7s | 视觉钩子 |
| 7–14s | 故事展开 |
| 14–21s | 冲突升级 |
| 21–26s | 高潮 |
| 26–28s | 结果 / 反转 |

五幕的叙事链固定为：

```
开始 → 发展 → 冲突升级 → 高潮 → 结果/反转
```

## 节奏原则

- **5 秒必须有一次变化**。可以是景别变化、情绪转折、动作爆发或声音事件。
- **钩子前置**。最强的画面或最反常的细节放在正片开头，不要藏着。
- **高潮只给一个**。21–26 秒是唯一的高点，前面所有铺垫都服务于它。
- **结尾留记忆点**。最后 2 秒给一个可被记住的画面或反转，不要平铺直叙地结束。

## 时长变体

用户指定其他时长时按比例伸缩，保持五幕完整、片头片尾各 1–2 秒：

| 总时长 | 正片 | 钩子 | 展开 | 升级 | 高潮 | 结果 |
| --- | --- | --- | --- | --- | --- | --- |
| 15s | 12s | 0–2s | 2–5s | 5–8s | 8–10s | 10–12s |
| 30s | 26s | 0–5s | 5–12s | 12–19s | 19–24s | 24–26s |
| 60s | 56s | 0–8s | 8–22s | 22–38s | 38–50s | 50–56s |

> 表中秒数为**正片内相对时间**。写最终时间轴时记得加上片头偏移（30 秒片的正片从第 2 秒开始）。

> 注意：竖屏短视频的黄金时长是 30 秒。超过 30 秒必须在展开段加第二个小冲突，否则中段会塌。
