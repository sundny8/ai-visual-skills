# 主体设计 & 场景设计

用户只给一句话，剩下的全靠补。补的原则是：**具体到可拍摄，不改变用户的核心意图**。

---

# 一、主体设计

## 人物类主体

逐项补全，每一项都要给出可视觉分辨的具体值：

| 维度 | 补什么 | 示例写法 |
| --- | --- | --- |
| 身份 | 职业/角色，暗示社会位置 | a field medic, a night-shift convenience store clerk |
| 年龄 | 具体数字或明确区间 | late 20s（不要写 young） |
| 外貌 | 脸型、五官、肤色、发型发色 | oval face, high cheekbones, deep-set eyes, warm olive skin, chin-length black hair tucked behind one ear |
| 服装 | 逐件 + 材质 + 颜色 + 磨损状态 | an oversized charcoal wool overcoat worn at the cuffs, a cream ribbed turtleneck, scuffed leather boots |
| 动作 | 正在做的具体动作，含接触点 | her right hand wrapped around a chipped enamel mug, steam rising |
| 表情 | 可拍摄的肌肉细节，不写情绪词 | jaw set, eyes narrowed a fraction, lips pressed thin |
| 姿态 | 身体朝向、重心、肩线 | weight shifted onto the back foot, shoulders angled away from the camera |
| 材质细节 | 皮肤、织物、金属、磨损 | visible pores, faint scar above the left brow, wool fibers catching the light |

## 产品类主体

| 维度 | 补什么 |
| --- | --- |
| 形态 | 轮廓、比例、体量 |
| 材质 | 玻璃/金属/皮革/陶瓷/塑料，及表面处理（拉丝、镜面、磨砂、喷砂） |
| 颜色 | 主色 + 点缀色 |
| 品牌调性 | 奢华 / 极简 / 科技 / 复古 / 手作 |
| 状态 | 全新 / 使用中 / 带磨损 |
| 交互 | 有没有手、有没有使用痕迹、有没有配套物件 |

产品广告里**手是高风险元素**——除非必要，不要加入手；必须加时写清手指位置与接触点。

## 生物类主体（奇幻/科幻）

除上述外，额外补：解剖结构、运动方式、与环境的关系。
奇幻生物必须**解剖自洽**——六条腿的承重方式要说得通，翅膀的展开面积要撑得住体重。

# 二、场景设计

## 必补维度

| 维度 | 内容 |
| --- | --- |
| 环境 | 室内/室外/半开放，具体场所 |
| 时代背景 | 当代 / 特定年代 / 架空 |
| 建筑 | 形制、材料、状态（完好/破败/在建） |
| 天气 | 晴/雨/雪/雾/风，及强度 |
| 空间层次 | 见下 |
| 背景元素 | 3–5 个可辨认的具体物件 |

## 空间三层结构（必做）

扁平是出图最常见的失败。必须显式写出三层：

| 层 | 作用 | 示例 |
| --- | --- | --- |
| **前景 Foreground** | 增加纵深与窥视感，可虚化 | out-of-focus railing bars across the lower left |
| **中景 Midground** | 主体所在层，最清晰 | the subject standing at the counter |
| **背景 Background** | 交代环境，柔化处理 | rain-streaked windows, blurred neon signage beyond |

**前景是最容易被忽略、也最能提升质感的一层。** 只要条件允许就加：门框、栏杆、树枝、人群虚影、蒸汽、玻璃反光、飘落的雨丝。

## 环境互动

让主体与场景发生物理接触，画面才有"活"的感觉：

- 踩过水洼 → 溅起的水花
- 手扶栏杆 → 掌心与金属的接触
- 风 → 衣摆与发丝的偏移
- 呼吸 → 冷空气中的白雾
- 桌面 → 杯底留下的水环

## 时代准确性（历史类必查）

服装剪裁 · 面料质感 · 器物形制 · 建筑细节 · 光源类型

历史题材一旦出现现代物件（拉链、塑料、现代字体、电灯），整张图的可信度立刻归零。

# 三、补全的边界

**可以补**：所有视觉细节——外貌、服装、光线、天气、背景、材质。

**不可以改**：
- 用户指定的主体身份
- 用户指定的核心动作或情境
- 用户指定的时代或世界观

补全是加血肉，不是换骨。用户说"一个女孩在雨中等人"，你可以决定她的年龄、穿什么、站在哪、什么天气、什么光——但**不能改成她在追人或者她在笑**。
