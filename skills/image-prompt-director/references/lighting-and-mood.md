# 光影与情绪配方

**原则：先定情绪，再倒推光位、光质、色温。** 不要随手加 "cinematic lighting" 了事。

---

## 四大主题配方

### 史诗 Epic

```
低角度逆光 + 黄金时刻 + 体积光
```

| 要素 | 写法 |
| --- | --- |
| 光位 | 逆光 / 侧逆光，光源在主体后方 |
| 光质 | 硬光，长阴影 |
| 色温 | 3200K–4500K 暖金 |
| 特征 | 轮廓光勾边、空气中的尘埃或雾被照亮成体积光、地面拉出长影 |
| 情绪 | 崇高、宿命、壮阔 |

关键词：`golden hour backlight, volumetric god rays through dust, long raking shadows, strong rim light outlining the silhouette, high dynamic range`

### 科幻 Sci-Fi

```
霓虹 + 冷色主调 + 反射面
```

| 要素 | 写法 |
| --- | --- |
| 光位 | 多光源（霓虹招牌、屏幕、指示灯），来自画面内 |
| 光质 | 混合——硬边霓虹 + 柔和的屏幕泛光 |
| 色温 | 5600K–8000K 冷蓝青，品红/青色点缀 |
| 特征 | 湿地面反射、玻璃反射、屏幕光打在脸上、体积雾 |
| 情绪 | 疏离、未来、技术崇拜 |

关键词：`neon signage reflections on wet asphalt, cold cyan and magenta practical lights, screen glow on skin, volumetric haze, glass and chrome specular highlights, teal and magenta palette`

### 东方 Eastern Aesthetics

```
柔光 + 留白 + 水墨层次
```

| 要素 | 写法 |
| --- | --- |
| 光位 | 侧窗自然光，柔和均匀 |
| 光质 | 柔光，低反差，过渡绵长 |
| 色温 | 4500K–5500K，偏中性带暖 |
| 特征 | 大量留白、纱/纸/木的透光质感、雾气层次、低饱和雅致色调 |
| 情绪 | 静谧、克制、含蓄 |

关键词：`soft diffused window light, extensive negative space, translucent paper and linen screens, layered mist, muted celadon and ink-wash palette, gentle tonal gradation, quiet and restrained mood`

### 恐怖 Horror

```
低调光 + 深阴影 + 压迫空间
```

| 要素 | 写法 |
| --- | --- |
| 光位 | 单一光源，且大部分画面沉入黑暗 |
| 光质 | 硬光，边缘锐利的阴影 |
| 色温 | 偏冷，或病态的绿色/琥珀色 |
| 特征 | 大面积极黑、光源在画面内可见但看不清全貌、天花板压低、门框切割画面 |
| 情绪 | 不安、被窥视、无处可逃 |

关键词：`single practical light source, low-key lighting, 80% of frame in near-black shadow, hard-edged shadows, oppressive low ceiling, doorframe framing the subject, sickly green or amber cast, deep crushed blacks`

## 通用光影参数

| 参数 | 选项 |
| --- | --- |
| 光位 | 顺光 / 侧光 / 侧逆光 / 逆光 / 顶光 / 底光 |
| 光质 | 硬光 hard / 柔光 soft / 混合 mixed |
| 光源数量 | 单光源 single-source / 三光源 three-point / 实用光源 practical |
| 色温 | 暖 3200K / 中性 5500K / 冷 6500K+ |
| 反差 | 高反差 high contrast / 低反差 low contrast |
| 特殊 | 体积光 volumetric / 轮廓光 rim light / 眼神光 catchlight / 明暗交界 chiaroscuro |

**光位必须写出方向**：`from camera left`、`from behind and above`、`from a single window at frame right`。只写"侧面打光"不够，模型会随机。

## 色彩分级

| 色调 | 写法 | 情绪 |
| --- | --- | --- |
| 青橙 | teal and orange grade | 通用电影感 |
| 暖金 | warm golden grade | 怀旧、希望、史诗 |
| 冷蓝 | cold blue grade | 孤独、科技、疏离 |
| 低饱和 | desaturated, muted grade | 战争、纪实、沉重 |
| 高饱和 | vivid saturated grade | 幻想、青春、商业 |
| 单色 | monochromatic | 风格化、概念 |
| 双色 | duotone | 海报、图形感 |

**全图统一色彩基调。** 允许冷暖对比（暖主体 + 冷背景），但不允许色彩散乱无主调。

## 光影常见错误

| 错误 | 修正 |
| --- | --- |
| 只写 "cinematic lighting" | 写明光位方向 + 光质 + 色温 |
| 逆光但脸全黑 | 补一句 `with a subtle fill on the face` |
| 多光源但说不清来源 | 每束光都要有画面内的来源（窗、灯、屏幕、霓虹） |
| 高反差却写了柔光 | 二选一，不要自相矛盾 |
| 光线与场景时间不符 | 白天室内不要写月光；烛光场景不要写 5500K 日光 |
