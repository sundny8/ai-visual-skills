# 图片类型与差异化策略

先判定类型，类型决定后面所有默认值。允许叠加（例如"科幻概念 + 海报"）。

---

## 1. 电影剧照 Cinematic Film Still

**核心**：像从一部真实电影里截下来的一帧，有前后文感。

| 维度 | 默认 |
| --- | --- |
| 画幅 | 2.39:1 宽幅 或 1.85:1 |
| 摄影机 | ARRI Alexa 65 |
| 镜头 | 35mm 或 50mm |
| 景深 | 真实浅景深 |
| 光影 | 动机光（画面里能看到光源），高反差 |
| 色彩 | Teal & Orange 或统一单色调 |
| 关键 | 人物在"做某件事的中途"，不是摆拍 |

**必须避免**：正脸看镜头的摆拍感、均匀布光、背景全虚。

---

## 2. 海报 Poster / Key Art

**核心**：留白为文字预留位置，视觉冲击最大化。

| 维度 | 默认 |
| --- | --- |
| 画幅 | 2:3 竖版 或 1:1 |
| 构图 | 中心构图 或 三分构图，主体占画面 40–60% |
| 空间 | 大片负空间，通常在上方或一侧 |
| 光影 | 强轮廓光把主体从背景中剥离 |
| 色彩 | 高对比，两到三色主调 |
| 关键 | 一张海报只讲一个概念 |

**必须避免**：画面塞满、主体太小、没有留白。

---

## 3. 人像摄影 Portrait Photography

**核心**：脸是唯一主角，皮肤与眼神是技术指标。

| 维度 | 默认 |
| --- | --- |
| 画幅 | 4:5 或 3:4 |
| 镜头 | 85mm（标准）或 135mm（压缩感） |
| 景深 | 极浅，眼睛锐利，耳后开始虚 |
| 光影 | 伦勃朗光 / 蝴蝶光 / 侧光，写出方向 |
| 背景 | 简洁，与人物有明度差 |
| 关键 | 皮肤质感、眼神光、发丝边缘光 |

**必须避免**：广角畸变、塑料皮肤、过度磨皮、眼神无光。

---

## 4. 产品广告 Product Advertising

**核心**：产品是英雄，材质要能被"摸到"。

| 维度 | 默认 |
| --- | --- |
| 画幅 | 1:1 或 4:5 |
| 镜头 | 100mm 微距 或 50mm |
| 景深 | 浅，产品全清晰，背景柔化 |
| 光影 | 大面积柔光箱 + 一条硬边高光带 |
| 背景 | 单色无缝背景或与产品调性呼应的场景 |
| 关键 | 表面反光、边缘高光、材质纹理、干净 |

**必须避免**：环境杂乱、产品失焦、高光过曝丢失细节、廉价塑料感。

---

## 5. 历史复原 Historical Reconstruction

**核心**：考据感。材质、服装、器物必须符合时代。

| 维度 | 默认 |
| --- | --- |
| 画幅 | 3:2 或 16:9 |
| 镜头 | 35mm |
| 景深 | 中等 |
| 光影 | 自然光为主，与时代光源一致（油灯、烛火、天光） |
| 色彩 | 低饱和，偏土黄/赭石/褪色感 |
| 关键 | 时代准确的道具、服装剪裁、建筑形制 |

**必须避免**：现代物件穿帮、现代面料质感、过于干净的场景。

---

## 6. 科幻概念 Sci-Fi Concept Art

**核心**：一个可信的"另一个世界"，有物理规则。

| 维度 | 默认 |
| --- | --- |
| 画幅 | 21:9 或 16:9 |
| 镜头 | 24mm 广角（规模感）或 35mm |
| 景深 | 中深，要看清世界 |
| 光影 | 霓虹、冷色主调、体积光、屏幕反射 |
| 色彩 | 青蓝 + 品红点缀 |
| 关键 | 尺度对比（人 vs 建筑）、功能性设计（看得出用途） |

**必须避免**：无意义堆砌机械零件、尺度混乱、光源无来源。

---

## 7. 奇幻艺术 Fantasy Art

**核心**：完整自洽的世界规则，可以非写实但必须可信。

| 维度 | 默认 |
| --- | --- |
| 画幅 | 2:3 或 16:9 |
| 镜头 | 35mm 或 50mm |
| 景深 | 中等 |
| 光影 | 戏剧化，可有非自然光源（魔法辉光） |
| 色彩 | 高饱和，冷暖对比强烈 |
| 关键 | 生物的解剖自洽、环境与角色呼应、魔法有视觉规则 |

**必须避免**：缝合怪（拼凑无逻辑）、比例失调、光照不统一。

---

## 8. 纪录片摄影 Documentary Photography

**核心**：观察者的视角，不介入。

| 维度 | 默认 |
| --- | --- |
| 画幅 | 3:2 |
| 镜头 | 35mm |
| 景深 | 中等偏深 |
| 光影 | 现场光，允许不完美 |
| 色彩 | 低饱和，接近自然 |
| 关键 | 抓拍感、环境信息量足、人物不摆姿势 |

**必须避免**：影棚布光感、过度后期、摆拍姿态。

---

## 类型叠加

| 组合 | 处理方式 |
| --- | --- |
| 科幻 + 海报 | 用海报的留白构图，用科幻的光影色彩 |
| 人像 + 电影剧照 | 用 85mm 的浅景深，但构图按宽幅电影帧 |
| 产品 + 纪录片 | 用纪录片的环境真实感，但产品仍是清晰主体 |

叠加时**以视觉呈现形式（剧照/海报/人像）定构图和镜头，以题材（科幻/历史/奇幻）定光影和色彩**。
